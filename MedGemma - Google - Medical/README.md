Build a local medical image diagnosis pipeline in Python using Google’s brand new MedGemma multimodal model! 

In this step-by-step tutorial, you will learn how to run Google's MedGemma-4b-it locally using PyTorch, Hugging Face Transformers, and 4-bit quantization with BitsAndBytes. You'll see how to inspect chest X-rays, dermatology lesions, histopathology slides, and fundus images right on consumer GPUs with as little as 4GB to 8GB of VRAM. <br/>

📌 What You’ll Learn: <br/>

💻 What is Google MedGemma  <br/>

💻 How to set up a Python environment for run clinical vision models locally <br/>

💻 Preprocessing medical images with AutoProcessor <br/>

💻 Structuring multimodal chat templates with clinical system instructions <br/>

💻 Generating zero-shot radiological impressions and pathology reports in Python <br/>
