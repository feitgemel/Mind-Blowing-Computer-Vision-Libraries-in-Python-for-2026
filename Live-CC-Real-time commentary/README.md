Learn how to build a real-time AI video captioning pipeline using Python, Qwen2-VL, and OpenCV. 

In this step-by-step tutorial, we walk through setting up LiveCC to analyze video streams frame-by-frame and generate continuous AI commentaries. We'll also integrate yt-dlp to stream and auto-caption any YouTube Shorts or video URL directly, complete with real-time preview overlays and hard-coded output video rendering. <br/>

📌 What You’ll Learn: <br/>

💻 Environment setup on WSL (PyTorch, Flash Attention 2, Liger Kernel) <br/>

💻 How to generate automatic captions for a local video , and a Youtube Video <br/>

💻 How streaming vision-language models (Qwen2-VL / LiveCC) handle temporal context <br/>

💻 Real-time text overlay and timestamp rendering with OpenCV <br/>

💻 Compiling subtitles MP4 videos with custom frame-matching logic <br/>
