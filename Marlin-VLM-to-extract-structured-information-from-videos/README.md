Turn any security camera feed into a searchable, smart AI monitor—running 100% locally on your GPU.

In this step-by-step tutorial, you’ll learn how to set up and run NemoStation’s Marlin-2B Vision-Language Model using Python, PyTorch, and WSL2. Instead of scrubbing through hours of CCTV footage manually, you'll build a Python script that finds exact timestamps using plain-English text queries, extracts a 15-frame visual evidence grid, and generates a complete scene-by-scene event timeline. <br/>

📌 What You’ll Learn: <br/>

💻 Setting up a clean Conda & WSL2 Linux environment for GPU video AI <br/>

💻 Installing PyTorch , torchcodec, FFmpeg, and Hugging Face Transformers <br/>

💻 Mode 1 (Temporal Grounding): Searching security footage with natural language (e.g., "a person walking close toward the camera") and generating a Matplotlib frame 15 frames grid <br/>

💻 Mode 2 (Full Scene Breakdown): Automatically captioning and logging timestamped events across an entire video clipest viewer <br/>
